# Portfolio

A four-page personal portfolio site for Luca Menasveta, freelance videographer.
Built for the GIT 215 Module 6 Code-Along as the HTML and CSS foundation that
Build 6 will expand on.

The site uses semantic HTML regions (`header`, `nav`, `main`, `footer`), a single
shared stylesheet, relative links between pages, and a mobile-first layout with
breakpoints at 600px and 900px.

## Pages

- **index.html** — home page, short introduction and a three-card summary of services
- **about.html** — background, how I got into video, and how I run a job
- **projects.html** — selected recent work and what I am building next
- **contact.html** — how to reach me and what to include in a first message

## Live site

https://lucamenasveta.github.io/portfolio/

## Built with

Plain HTML and CSS. CSS Grid lays out the page regions, Flexbox handles the
navigation bar and the card row, and two media queries widen the layout from a
single stacked column on phones to a horizontal nav with three cards across on
desktop. The stylesheet carries an authorship comment and a documented colour
palette.
